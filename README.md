# Python题库

一个包含Python考试题目和详细解析的在线刷题系统。

## 项目说明

本项目包含5套Python考试试卷，共计约245道题目，涵盖单选题、填空题、判断题和程序设计题。

## 文件结构

```
Python题库/
├── Python刷题.html      # 主页面 - 在线刷题系统
├── answers_data.json    # 题目答案和解析数据
├── 题目/                # 原始题目图片文件夹
├── README.md            # 项目说明
└── .gitignore           # Git忽略文件
```

## 使用方式

1. 直接在浏览器中打开 `Python刷题.html` 文件
2. 或者启动本地服务器访问：
   ```bash
   python -m http.server 8080
   # 然后访问 http://localhost:8080/Python刷题.html
   ```

## 功能特点

- 支持5套试卷切换
- 按空格键显示/隐藏答案和解析
- 左右箭头切换题目
- 数字键1-5快速切换试卷
- 每道题都有详细的答案解析
